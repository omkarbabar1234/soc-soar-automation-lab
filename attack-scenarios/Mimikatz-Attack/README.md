# 🧠 Credential Access via Mimikatz (Windows)

## 📌 Overview
This scenario simulates a credential access attack on a Windows endpoint using **Mimikatz** and demonstrates how a SOC detects suspicious activity, enriches indicators, and creates an incident for analyst investigation using SIEM, SOAR, and case management tools.

---

## 🧪 Lab Environment

### Target System
- Windows virtual machine (on-prem)
- Sysmon enabled
- Wazuh agent installed

### Attack Tool
- **Mimikatz**
- Downloaded and executed manually on the Windows VM

### SOC Tooling
- **Wazuh** (AWS) — SIEM / endpoint telemetry
- **Shuffle** (Cloud) — SOAR orchestration
- **TheHive** (AWS) — case management
- **Email** — analyst notification
- **VirusTotal** — hash enrichment

---

## 🧪 Attack Simulation
1. Mimikatz was downloaded and executed on the Windows system to simulate credential dumping activity.
2. The execution generated suspicious process and memory-access behavior.
3. Sysmon captured detailed process creation and related security events.
4. Wazuh collected these events from the endpoint and analyzed them centrally.

---

## 🔍 Detection Logic
- Sysmon logs generated by the Windows endpoint are forwarded to Wazuh.
- Wazuh correlation rules identify suspicious behavior associated with credential dumping tools.
- When a matching rule is triggered, Wazuh generates a **high-severity alert**.
- The alert is mapped to **MITRE ATT&CK technique T1003 – OS Credential Dumping**.

---

## 🔗 SOAR Workflow
1. Wazuh sends the alert to Shuffle via webhook.
2. Shuffle extracts the file hash from the alert using regex.
3. The extracted hash is enriched using **VirusTotal**.
4. An email notification is sent to the analyst with alert details.
5. A case is created in **TheHive** for investigation and tracking.

---

## 🚨 Alert & Case Management
- TheHive is used strictly for **case creation and investigation**, not response execution.
- Analysts can review:
  - Detection details
  - Enrichment results
  - Timeline of activity
- Email notifications ensure analyst awareness and timely response.

---

## 🔑 Key Takeaways
- Demonstrates detection of credential access activity on Windows endpoints
- Shows integration between endpoint telemetry, SIEM, SOAR, and case management
- Uses enrichment to add context before analyst review
- Avoids unsafe automatic remediation
